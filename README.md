# Simulatore Netto da RAL

Prototipo per stimare la retribuzione netta mensile e annuale a partire dalla RAL (Retribuzione Annua Lorda), con IRPEF, addizionali regionale/comunale e mensilità aggiuntive (tredicesima/quattordicesima).

Questa simulazione è pensata per ottenere uno strumento funzionante e di rapido utilizzo, non per coprire ogni casistica: contiene quindi delle semplificazioni. In particolare considera solo il caso di un dipendente a tempo indeterminato con residenza fiscale nel Comune di Milano.

**Link live:**
https://lucazanoni.github.io/Simulatore-Netto-da-RAL/

## Disclaimer

Prototipo a scopo illustrativo — non sostituisce un cedolino ufficiale né una consulenza fiscale.
